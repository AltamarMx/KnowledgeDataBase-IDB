# Instalar Open Studio

Procedimiento para instalar Open Studio Application v1.11.0, la versión acordada para el curso.

## Pasos

1. Ir a **OpenStudio Coalition** website (openstudiocoalition.org)
2. Buscar **Open Studio Application** (NO el SDK, NO el plugin de SketchUp)
3. Hacer clic → lleva a **GitHub releases**
4. En la sección **Assets**, descargar el instalador según tu sistema operativo:
   - **Windows:** archivo `.exe`
   - **Mac:** archivo `.dmg` (requiere macOS 13 o superior)
   - **Ubuntu:** archivo `.deb` (solo Ubuntu 22 o 24)
5. Ejecutar el instalador (~320 MB de descarga)
6. Verificar que se instaló la versión **1.11.0**

## Notas importantes

- **NO instalar el SDK** — es para desarrolladores y solo funciona a nivel de terminal (no tiene interfaz gráfica)
- Open Studio trae incluida una instalación de Energy Plus — **no es necesario instalar Energy Plus por separado**
- Todos en el curso deben usar la **misma versión** (1.11.0) para compatibilidad de archivos
- Versiones superiores pueden abrir archivos de versiones anteriores, pero no al revés
